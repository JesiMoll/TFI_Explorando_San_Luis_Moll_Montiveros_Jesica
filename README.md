                                           Explorando San Luis

Descripción:

Este proyecto lo desarrollé para el Trabajo Final Integrador de la materia Programación Web I.

Elegí realizar una página turística sobre la provincia de San Luis.

Mi objetivo es mostrar algunos paisajes y destinos turísticos de la provincia, utilizando los contenidos aprendidos en la materia.

Contenido del sitio:

El sitio cuenta con tres páginas:

-Inicio:presentación de San Luis y un carrusel de fotografías que se puede recorrer con los botones anterior y siguiente.
-Destinos: información sobre Sierras de las Quijadas, San Francisco del Monte de Oro y La Punta, con fotografías y enlaces a Google Maps.
-Contacto: formulario con validaciones realizadas en JavaScript y un resumen de los datos ingresados.

Tecnologías utilizadas:

-HTML para organizar el contenido.
-CSS y Flexbox para el diseño.
-JavaScript para el carrusel y la validación del formulario.

Cómo utilizarlo:
Para utilizar el proyecto de manera local, descargar los archivos y abrir `index.html` en un navegador.
Desde el menú principal se puede acceder a las distintas páginas.
